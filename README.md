# TP3-Laboratorio-de-programacion
Sistema de Gestión de Stock Multirubro  
**Comercio: El Kiosco de Lu**  
(Kiosco • Librería • Regalería)

![Logo del comercio](./img/logo.png)

## Descripción del proyecto
Sitio web estático desarrollado como Trabajo Práctico N°3 para la materia **Laboratorio de Programación - 6° G**.  
El objetivo es simular un sistema básico de gestión de stock para un comercio multirubro utilizando únicamente **HTML5** y **CSS3** (sin JavaScript).

### Funcionalidades implementadas
- Página principal con presentación del comercio y tabla de productos destacados
- Página de gestión de productos con formulario para agregar/editar ítems
- Página de registro de ventas con histórico de transacciones y pagos a cuenta
- Diseño responsive básico y uso de Flexbox/Grid
- Estilos personalizados con hoja externa CSS
- Comentarios detallados en código HTML y CSS

## Estructura del proyecto
TP3-stock-multirubro/
├── index.html          → Página principal
├── gestion.html        → Gestión de productos
├── ventas.html         → Registro de ventas
├── style.css           → Hoja de estilos externa

## Tecnologías utilizadas
- HTML5 (etiquetas semánticas)
- CSS3 (Flexbox, selectores avanzados, hover, comentarios)
- GitHub Pages para publicación

## Páginas del sitio

### 1. Inicio (`index.html`)
- Header con logo y nombre del comercio
- Tabla de productos destacados (15 productos: 5 de cada rubro)
- Navegación hacia las demás secciones

### 2. Gestión de Stock (`gestion.html`)
- Formulario completo para agregar o modificar productos
- Campos: Nombre, Rubro (select), Precio, Stock
- Botón "Guardar" simulado

### 3. Ventas (`ventas.html`)
- Tabla de transacciones realizadas
- Sección de "Pagos a cuenta" con clientes ficticios
